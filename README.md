# caso-algoritmos-montano

Repositorio para el portafolio de aprendizaje de la materia de **Análisis de Algoritmos** — Universidad Adventista de Bolivia.

**Estudiante:** Fabian Montaño Mina  
 **Proceso real:** Motor de alertas y emparejamiento automático de una plataforma inmobiliaria para el cruce de nuevas propiedades frente a búsquedas guardadas de clientes por zona, rango de precio y atributos.

---

## Índice del Expediente

- **[hitos/h1/]()**
  - **Descripción:** Elección y caracterización del proceso real a optimizar, argumentación del cuello de botella y dataset de ejemplo de propiedades.
  - **Link: https://github.com/FfabiannM/caso-algoritmos-montano/tree/main/hitos/h1**

- **[practicas/]()**
  - **Descripción:** Prácticas de laboratorio (C3 a C6): mediciones de tiempo empírico, comparación de búsqueda lineal vs. binaria, torneo de ordenamientos y selección justificada para el caso inmobiliario.
  - **Link: https://github.com/FfabiannM/caso-algoritmos-montano/tree/main/practicas**

- **[hitos/h2/]()**
  - **Descripción:** Inventario de operaciones del caso de negocio, propuesta de estructuras de datos (Tablas Hash y árboles balanceados) y medición comparativa de rendimiento.
  - **Link: https://github.com/FfabiannM/caso-algoritmos-montano/tree/main/hitos/h2**

- **[hitos/h3/]()**
  - **Descripción:** Estrategia algorítmica, modelado complementario con grafos ponderados de zonas para recomendaciones geográficas y comparación de enfoques.
  - **Link: https://github.com/FfabiannM/caso-algoritmos-montano/tree/main/hitos/h3**
